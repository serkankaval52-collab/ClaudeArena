# CoreFactory Framework — Source Inventory and Contracts

- Status: inventory document. It describes the repository; it does not contain the repository.
- Canonical rule: every source file listed here is canonical at its own path. This document never duplicates source code.
- Authoritative file list: `git ls-files Assets Packages` always wins over this document.

## Why this document no longer contains code

An earlier version of this file carried full copies of seventeen source files. Those copies drifted from the sources they claimed to describe. At the time this rewrite was made, nine of the seventeen copies no longer matched the real file, and one pointed at a path that does not exist. A copy that silently disagrees with the source is worse than no copy at all, because a reader cannot tell which one is true.

The same problem was removed from `GAME_FACTORY_ORCHESTRATION_SETUP.md` for the rollback tool and the localization translator. This file now follows that pattern.

## SECTION 9: Open defects referenced above

These are recorded here only as pointers. They are not fixed by this document.

- D-01 `UIThemeGenerator` assigns `primaryFont` but never assigns `fallbackFonts`. CJK and Arabic text is expected to render as tofu. `FactoryPreflight` deliberately blocks builds while this is unresolved.
- D-02 `HapticBridge.mm.meta` uses keys that are not part of Unity's PluginImporter schema. Whether the ARC compile flag survives import is unverified.
- D-03 `PrivacyInfo.xcprivacy` declares tracking, but no App Tracking Transparency request exists anywhere in the codebase and there is no `Info.plist`.

## SECTION 10: What is not in this repository

`ProjectSettings/`, `ProjectVersion.txt`, `packages-lock.json`, `AndroidManifest.xml`, scenes, prefabs, `Assets/Resources`, and generated theme assets are all absent. Every one of them is produced by Unity, not by hand.

No claim in this repository about compilation success, test results, store compliance, or production readiness has been verified by a Unity Editor. To create the missing files, follow `docs/runbooks/RUNBOOK-01-first-unity-session.md`.
